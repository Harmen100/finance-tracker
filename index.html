How to export from CIBC
  1. Log in at cibc.com and go to Online Banking
  2. Click More in the top nav, then Download Transactions
  3. Select your chequing or savings account and the date range
  4. Choose CSV format and download the file
  5. Drop the file below
Handles CIBC layouts with separate Debit/Credit columns or a single signed Amount column. Categories are auto-detected from descriptions.
Preview
How to export from Wealthsimple (TFSA / RRSP / FHSA / Invest)
  1. Log in at my.wealthsimple.com
  2. Click your investment account (TFSA, RRSP, or FHSA)
  3. Go to Activity and click Download or Export CSV
  4. Alternatively: Profile → Documents → Transaction History CSV
  5. Select the account type below, then drop the file
Detects Buy, Sell, and Dividend rows. Holdings are updated automatically from buy/sell trades.
Preview
How to export from Wealthsimple Cash / Crypto
  1. Log in at my.wealthsimple.com
  2. Open your Cash or Crypto account
  3. Click Activity → View all transactions
  4. Click Download or Export — if not visible, use the free Wealthsimple CSV exporter browser script
  5. Select account type below, then drop the file
Positive amounts = income/deposits. Negative amounts = expenses/withdrawals. Categories are auto-detected.
